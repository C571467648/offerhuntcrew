# 00_交互区 · 面向你的交互区

> 这是你和整个 AI 团队之间的"窗口"。你放文件在这里，老师们把报告放到这里给你看。

## 目录结构

```
00_交互区/
├── 用户提供/     ← 你把材料放这里（简历、成绩单、反馈、情报源）
└── 系统输出/     ← 老师们给你的产出都在这里（报告/看板/修改稿）
```

## 📌 用户提供/ 放置指引

| 材料 | 放置位置 | 说明 |
|---|---|---|
| 简历（定稿） | `用户提供/` | 先放在这里，再复制一份到 `01_共享区/20_简历库/`（见下） |
| 成绩单（可选） | `用户提供/` | 老师需要时读取 |
| 投递情况/反馈 | `用户提供/` | 你手头的投递记录、面试反馈等，直接放这里并告诉老师 |
| 校招情报源（可选） | `用户提供/情报源/` | 你关注的信息汇总表（如腾讯文档链接、官网清单），放一个说明文件即可，选岗老师会纳入例行扫描 |
| 新增求职方向说明 | `用户提供/` | 你要简历优化老师写新方向简历时，把要求放这里 |

## 系统输出/ 说明

老师们给你的所有产出（投递看板、今日+本周待办看板、情报清单、辅导报告、简历修改稿等）都会放在这里，按子目录归类。**你只需要在这里查看文件即可，无需自己整理。**

## 重要提醒

1. **简历库**：定稿简历的"正式存档"在 `01_共享区/20_简历库/`（五位老师只读）。你把简历放进 `用户提供/` 后，老师会引导你把定稿复制过去。
2. **材料命名**：建议用"简历-求职方向"命名（如 `简历-C++.docx`），方便老师区分多个版本。
3. 文件格式：简历建议 PDF + Word 各一份；表格用 xlsx/csv；文字说明用 md/txt。
