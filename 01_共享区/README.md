# 01_共享区 · 五位老师的协作区

> 这是整个 AI 团队的"工作群"。跨角色信息一律落盘本区，以文件为准，对话内讨论不作数。

## 目录结构

```
01_共享区/
├── 00_通知板/     ← 跨角色留言与@提醒（格式见模板）
├── 10_任务移交/   ← 任务单（派单/接单/回执）
├── 20_简历库/     ← 用户手动投放的定稿简历（全员只读，禁止写入！）
├── 90_会话纪要/   ← 各对话关键决策留档
└── 90_用户画像/   ← 用户的求职档案（班主任维护）
```

## 各目录用途

| 目录 | 谁来写 | 内容 |
|---|---|---|
| 00_通知板 | 任何角色 | 需要他人知晓的信息，命名 `[日期]_[发送者]_[接收者]_[主题].md` |
| 10_任务移交 | 总架构师派单 | 任务单，含任务描述/验收标准/截止时间/状态 |
| 20_简历库 | 仅用户 | 定稿简历。**所有老师只读**，修改产出走 `00_交互区/系统输出/` |
| 90_会话纪要 | 任何角色 | 重要决策、结论留档 |
| 90_用户画像 | 班主任 | 用户档案（学校/意向城市/方向/目标等），其他老师参考 |

## 给用户的提醒

- **20_简历库**：把你最终的定稿简历放这里（从 `00_交互区/用户提供/` 复制过来即可）。这是全团队的简历依据。
- **90_用户画像**：班主任第一次对话时会帮你建档。档案信息有变化（如意向城市变了、拿到 offer 了），直接告诉班主任更新。
