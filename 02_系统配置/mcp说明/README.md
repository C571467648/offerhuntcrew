# MCP 说明目录

> 本目录存放系统涉及的 MCP 说明。**无需手动安装任何东西**——所有安装、注册均由总架构师在配置阶段指导完成。

## 必需

- **office-mcp**：文档处理（Word/Excel/PPT）。系统核心能力，负责读写简历、投递总表、生成报表。需配合本地 LibreOffice。

## 可选

- **mcp-jobs**：岗位搜索辅助（关键词+城市，偏社招/私企），选岗老师采集情报的补充手段。
- **JobSniper**：岗位知识库检索（高级）。智联自动采集依赖 WSL，普通用户默认不启用。

## 安装与注册

完整说明、注册配置模板、环境检查见：`03_总架构师/项目要求与MCP清单.md`（总架构师据此引导用户安装）。
