# MCP 说明目录

> 本目录存放系统涉及的 MCP 说明。**无需手动安装任何东西**——所有安装、注册均由总架构师在配置阶段指导完成。
>
> **平台提示**：本系统同时支持 **Trae** 和 **TraeWork** 两个平台。不同平台可用的 MCP 不同，总架构师会自动适配。详细对比见 `02_系统配置/平台适配/平台对比.md`。

---

## 必需（两个平台都需要）

- **office-mcp**：文档处理（Word/Excel/PPT）。系统核心能力，负责读写简历、投递总表、生成报表。需配合本地 LibreOffice。
  - 安装方式：手动 clone + venv + pip 安装
  - 详细配置：`03_总架构师/项目要求与MCP清单.md` 第 2.1 节

---

## Trae 平台可选

- **mcp-jobs**：岗位搜索辅助（关键词+城市，偏社招/私企），选岗老师采集情报的补充手段。
- **JobSniper**：岗位知识库检索（高级）。智联自动采集依赖 WSL，普通用户默认不启用。

---

## TraeWork 平台强推荐（从 MCP 市场一键添加）

- **腾讯文档 MCP（4个）**：
  - `sheet-mcp`：在线表格读写，核心价值是直接读取校招汇总腾讯文档（API 级，比浏览器方案快数倍）
  - `doc-mcp`：在线文档读写
  - `slide-mcp`：在线幻灯片（备用）
  - `tencent-docs（综合）`：空间管理、网页剪藏、OCR
- **Knowledge Graph Memory**：跨会话知识图谱记忆，沉淀用户画像与决策记录
