# 投递状态机（统一规范 v1.0）

> 适用：所有投递总表（央国企表、私企表、看板、战报）。字段名与状态取值全局唯一，禁止自创。

## 1. 字段定义（表头统一）

| 字段 | 必填 | 说明 |
|---|---|---|
| 公司 | ✅ | 公司全称，如"某公司" |
| 批次 | ✅ | 提前批 / 正式批 / 补录 / 实习 |
| 地点 | ｜ | 工作地，多个用"、"分隔 |
| 优先级 | ✅ | 高 / 一般 / 低 |
| 岗位 | ✅ | 投递岗位名；多个志愿用"<br>"分隔 |
| 是否投递 | ✅ | 是 / 否 / 计划投 |
| 投递日期 | ｜ | YYYY-MM-DD |
| 网申截止 | ｜ | YYYY-MM-DD，未知填"预计" |
| 测评截止 | ｜ | YYYY-MM-DD |
| 简历 | ✅ | 简历筛选阶段状态 |
| 测评 | ｜ | 测评阶段状态（无测评填"无"） |
| 笔试 | ｜ | 笔试阶段状态（无笔试填"无"） |
| 一面 | ｜ | 一面状态 |
| 二面 | ｜ | 二面状态 |
| 三面 | ｜ | 三面状态 |
| offer | ｜ | offer 状态（无则空） |
| 链接 | ｜ | 投递入口链接 |

## 2. 阶段状态取值（唯一允许值）

| 取值 | 含义 | 适用阶段 |
|---|---|---|
| （空） | 未到该阶段 / 未进行 | 全部 |
| 待参加 | 已收到邀请，尚未参加 | 测评/笔试/各面 |
| 过 | 已通过该阶段 | 全部 |
| 挂 | 该阶段被淘汰（终态） | 全部 |
| 已完成 | 该阶段已完成、结果未出 | 测评/笔试 |
| 无 | 该环节不存在（如无测评） | 测评/笔试 |
| - | 免试/不适用 | 全部 |

## 3. 流转规则

1. 阶段严格串行推进：简历 → 测评 → 笔试 → 一面 → 二面 → 三面 → offer。
2. 任一阶段为「挂」：其后所有阶段置空，整体状态记为「已挂」，不再推进。
3. 出现「offer」：公司整体状态记为「已获offer」。
4. 「过」只表示通过本阶段，不代表已到下一阶段；下一阶段状态由实际进展决定。
5. 禁止使用非规范取值（如"过了""笔试过了""秒挂"等口语），统一映射为规范值。

## 4. 记录规范

- 唯一写入者：选岗老师（`05_选岗老师/数据/` 主表）。
- 更新时机：用户反馈投递/笔面试结果后 24h 内更新，并同步生成看板。
- 战报（`00_交互区/系统输出/`）必须引用本状态机取值，供学习指导老师做复盘素材。
