# Trae vs TraeWork 平台对比与适配指南

> 本系统同时支持 **Trae** 和 **TraeWork** 两个平台。总架构师会在首次对话时自动检测并适配。用户也可以手动选择。

---

## 一、快速选择

| 你是... | 推荐平台 | 理由 |
|---|---|---|
| 新手 / 想免费 / 不想折腾 | **Trae** | 免费额度够用，安装简单，系统功能完整 |
| 追求效率 / 已有 TraeWork | **TraeWork** | 腾讯文档 MCP 直接读校招汇总表，效率提升明显 |
| 技术党 / 喜欢折腾 | **TraeWork** | 插件系统、内置 Skill、知识图谱记忆，可玩度高 |

> **一句话**：新手用 Trae 跑通，进阶用 TraeWork 提效。数据和规则完全通用，随时可以迁移。

---

## 二、功能对比表

| 维度 | Trae（基础版） | TraeWork（进阶版） |
|---|---|---|
| **费用** | 免费额度 + 可自配 API | 免费额度 + 可自配 API |
| **MCP 支持** | ✅ 手动添加 | ✅ 手动添加 + MCP 市场一键安装 |
| **内置 Skill** | 基础 | 丰富（xlsx/docx/pdf/html-report/dynamic-ui 等） |
| **插件系统** | ❌ 无 | ✅ 有（浏览器控制、飞书、Seedream 等） |
| **知识图谱记忆** | ❌ 无（仅落盘文件） | ✅ Knowledge Graph Memory MCP |
| **腾讯文档 MCP** | ❌ 无 | ✅ 4 个（sheet/doc/slide/综合） |
| **浏览器自动化** | WebSearch/WebFetch 内置 | TRAE-browseruse skill + 浏览器插件 |
| **本系统体验** | 完整功能 | 增强体验（情报采集更快、工具更丰富） |

## 四、迁移指南（Trae → TraeWork）

如果你已经在 Trae 上跑通了系统，想迁移到 TraeWork：

1. **数据不动**：所有数据（简历、投递表、看板、用户档案）都在本地文件夹里，无需迁移
2. **打开方式**：在 TraeWork 中用"打开文件夹"打开同一个项目文件夹
3. **重新创建对话**：在 TraeWork 中重新创建 5 个老师的对话（复制初始提示词）
4. **新增配置**：
   - 从 MCP 市场添加腾讯文档 MCP（4个）
   - 可选：添加 Knowledge Graph Memory
   - office-mcp 仍需手动配置（或复用原有的配置）
5. **通知总架构师**：告诉它"我现在用的是 TraeWork"，它会调整所有老师的工具方案
6. **继续使用**：数据和规则完全兼容，直接继续即可

## 五、常见问题

**Q：两个平台的数据互通吗？**
A：完全互通。所有数据都存在本地文件夹里，平台只是"读取和操作这些数据的工具"。同一个文件夹在 Trae 和 TraeWork 中都能打开。

**Q：从 Trae 迁到 TraeWork，之前的投递记录会丢吗？**
A：不会。投递记录在 Excel 里，简历在简历库里，都在本地文件夹里。迁移平台不影响数据。

**Q：TraeWork 比 Trae 好很多吗？值得迁移吗？**
A：如果你主要用选岗功能（搜集岗位情报），值得——腾讯文档 MCP 比浏览器直读快很多。如果你更看重简历优化、面试辅导等，差异不大。

**Q：我可以两个都用吗？**
A：可以，但不建议同时开（可能导致对话记忆分散）。建议主用一个，另一个备用。

**Q：Cursor / Cline / 其他客户端能用吗？**
A：理论上支持 MCP 的客户端都能用，但本系统按 Trae/TraeWork 设计和测试。其他客户端可能需要手动调整配置。
