# 任务移交单 · 使用模板

> 位置：`01_共享区/10_任务移交/`。文件命名：`[任务ID]_[发起者]_[接收者].md`。任务ID 格式：T+日期+序号，如 `T20260827-01`。

```
---
任务ID：T20260827-01
发起者：总架构师
接收者：简历优化老师
状态：待接单          ← 待接单 → 进行中 → 已完成
截止时间：2026-08-30
---
## 任务描述
用户新增"XX方向"求职需求，需产出对应方向简历。

## 验收标准
1. 产出简历修改稿 .docx + 修改说明，输出到 00_交互区/系统输出/。
2. 修改说明含：改了哪些板块、为什么、与岗位匹配点。

## 备注
素材：01_共享区/20_简历库/（定稿简历）
```

## 状态流转（在原文件内更新）

1. 接收者开工：把 `待接单` 改为 `进行中`，追加一行 `接单：YYYY-MM-DD [角色名]`。
2. 完成后：改为 `已完成`，追加 `回执：YYYY-MM-DD 完成情况摘要 + 产出路径`。
3. 逾期未完成：班主任负责在通知板@催办；仍无法推进，升级总架构师。

## 填写规则

- 任务描述必须可执行、可验收；禁止模糊指令（如"优化一下"）。
- 一个任务单只放一个任务；多任务拆多单。
- 会话纪要类决策不占任务单，写 `01_共享区/90_会话纪要/`。
