# 会话纪要 · 使用模板

> 位置：`01_共享区/90_会话纪要/`。文件命名：`[日期]_[角色名]_[主题].md`
> 用途：记录跨对话的重要决策，防止信息丢失。**对话内讨论不作数，以纪要为准。**

```
---
日期：2026-08-27
角色：总架构师
主题：用户确认系统 V2 方案
---
## 决策
1. 五位老师体系确立（总架构师/班主任/选岗老师/学习指导老师/简历优化老师）。
2. 投递数据主副本归选岗老师，简历定稿放 20_简历库（用户手动投）。
3. office-mcp 安装于 02_系统配置/mcp/。

## 影响
- 后续所有角色 README 以本文档为基准。
```

## 填写规则

- 只记**决策与结论**，不记对话过程。
- 每份纪要控制在 10 行以内，超长则拆主题。
- 用户的重要偏好与规则变更，同时沉淀到项目记忆。
