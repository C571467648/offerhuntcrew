# 通知板 · 使用模板

> 位置：`01_共享区/00_通知板/`。文件命名：`[日期]_[发送者]_[接收者]_[主题].md`

```
---
发送者：选岗老师
接收者：班主任
时间：2026-08-27
主题：XX公司一面通过，笔试待安排
---
正文：
1. XX公司（正式批/高优先级）一面已通过，笔试预计本周内，请纳入 DDL 看板。
2. 附件：05_选岗老师/数据/秋招私企投递记录表.xlsx
```

## 填写规则

1. **首部 4 项必填**：发送者 / 接收者 / 时间 / 主题。
2. 正文只写结论与必要数据，禁止寒暄客套、禁止重复已有信息。
3. 涉及文件的写相对路径（相对根目录），不粘贴大段内容。
4. 接收者处理后，在原文件末尾追加一行 `已处理：YYYY-MM-DD [角色名]`，不留置不回执。
5. 若接收者回复多个角色，写多份通知或正文中列明 @角色。
