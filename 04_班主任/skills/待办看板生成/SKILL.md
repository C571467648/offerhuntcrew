# 待办看板生成流程

## 前置
- 待办文档已与用户确认并落盘：`04_班主任/待办历史/[日期]_班主任_待办.md`（历史归档+当天文件都在这里）
- **真实时间查询（强制，仅当需要日期/时间时）**：**禁止使用 AI 客户端注入的对话日期**（可能滞后，例：本机已是 8-28 注入仍显示 8-27）。需要以"今天/当前时间"为产出的，用本机命令实测：PowerShell `Get-Date -Format 'yyyy-MM-dd HH:mm'` 或 Python `datetime.datetime.now().strftime('%Y-%m-%d %H:%M')`；查不到时向用户确认。不涉及日期/时间时无需查询。
- **文件命名纪律（强制）**：每次更新待办 = **新建当天日期的新文件**（如 `2026-08-28_班主任_待办.md`），标题「今日待办（2026-08-28 …）」里的日期必须与文件名一致；**严禁在旧日期的文件上直接改内容**（否则看板日期不变，用户旧勾选无法清除）。旧文件自动成为历史归档，无需删除。
- **落盘验证（强制）**：生成看板前，先用文件工具列出 `04_班主任/待办历史/` 确认**当天日期的文件真实存在**、标题日期=文件名日期=今天；文件不在/日期不对 = 待办未落盘，**禁止生成看板**。
- 生成脚本（固定接口）：`04_班主任/可视化/update_todo.py`
- 模板：`04_班主任/可视化/todo_template.html`（样式/布局，一般不动）
- 输出：`04_班主任/可视化/待办看板.html`（覆盖）

## 执行责任（强制）
- **看板生成脚本必须由你自己（班主任）运行**，生成后告知用户快捷方式位置即可（`00_交互区/系统输出/待办看板.lnk`，双击即开），**绝不让用户手动运行任何命令**。
- 若当前对话环境无法运行 Python（如沙箱受限）：改用本机已装环境（本地 conda 环境或 `02_系统配置/mcp/office-mcp/.venv`）运行，或通知总架构师代为执行；**不要把命令丢给用户**。
- 每次生成后，**可询问用户**是否需要把快捷方式复制到桌面（.lnk 仅是指针，不占内存、不占磁盘）；用户同意则复制，桌面放置不影响看板本体。

## 核心流程（推荐，最省事）
> 待办确认后，只需两步。

1. 运行固定接口脚本生成看板：
   `python "04_班主任/可视化/update_todo.py"`
   （自动：读 `04_班主任/待办历史/` 最新一份 `*_班主任_待办.md` → 解析今日/本周两节 → 注入模板 → 生成看板）
2. 确认交互区快捷方式存在：`00_交互区/系统输出/待办看板.lnk`（直接指向 `待办看板.html`，双击用默认浏览器打开）。

## 看板功能（对用户）
- 今日待办 / 本周待办两个分区，事项+优先级+截止时间
- 顶部进度统计条：今日 X/Y、本周 X/Y（带进度条）
- 每项前有勾选框：勾选 = 完成（划线置灰），再点取消；状态保存在**浏览器本地（localStorage）**，下次打开自动恢复
- 深色模式切换（记住偏好）
- 纯 HTML/CSS/JS，无 CDN、无需联网、无需本地服务，直接双击文件即可打开

## 注意
- **必须先与用户确认待办内容并落盘 MD**，再生成看板；不要直接跳过确认环节。
- 待办内容改动时：改 MD（按前置纪律新建当天文件）→ 重新运行脚本即可刷新看板。
- **勾选自动清理规则**：今日待办按「天」隔离、本周待办按「周」隔离——每天更新今日待办后，昨日勾选自动清空（新一天重勾）；同一周内本周勾选保留，**跨周后自动清空**。此规则由看板自动执行，无需手工干预。
- **勾选状态只保存在用户本机浏览器中**：清理浏览器缓存/站点数据会丢失勾选记录——需提前提醒用户；换电脑/换浏览器也不可见。
- 看板是纯静态 HTML，双击打开时以 `file://` 方式运行，localStorage 按本地文件生效（无需服务器）。

## 环境依赖
- Python（仅标准库，无需额外安装）。

## 自查
- 看板标题日期 = 待办 MD 日期；今日/本周条数与 MD 一致；打开看板能勾选并刷新后保持。

## 输出
- `04_班主任/可视化/待办看板.html`（覆盖更新）
- `00_交互区/系统输出/待办看板.lnk`（快捷方式，双击即开）
