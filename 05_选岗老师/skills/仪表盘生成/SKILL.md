# 仪表盘生成流程

## 前置
- 数据源：
  - `05_选岗老师/数据/` 两个 xlsx（央国企表、私企表），**列名严格按状态机规范，勿改表头**
  - `05_选岗老师/岗位情报/新增岗位情报.xlsx`（可选，列：分类/公司/性质/届别/岗位/地点/截止窗口/匹配度/备注/入口；无此文件时看板情报模块显示空态）
- 生成脚本（固定接口）：`05_选岗老师/可视化/update_dashboard.py`
- 模板：`05_选岗老师/可视化/dashboard_template.html`（样式/布局，一般不动）
- 输出：`05_选岗老师/可视化/投递看板.html`（覆盖），交互区 `00_交互区/系统输出/投递看板.lnk` 快捷方式指向它
- **真实时间查询（强制，仅当需要日期/时间时）**：**禁止使用 AI 客户端注入的对话日期**（可能滞后）。情报清单文件名日期、看板标题日期等以"今天/当前时间"为产出的，先用本机命令实测：PowerShell `Get-Date -Format 'yyyy-MM-dd HH:mm'` 或 Python `datetime.datetime.now().strftime('%Y-%m-%d %H:%M')`；查不到时向用户确认。不涉及日期/时间时无需查询。

## 执行责任（强制）
- **看板生成脚本必须由你自己（选岗老师）运行**，生成后告知用户快捷方式位置即可（`00_交互区/系统输出/投递看板.lnk`，双击即开），**绝不让用户手动运行任何命令**。
- 若当前对话环境无法运行 Python（如沙箱受限）：改用本机已装环境（本地 conda 环境或 `02_系统配置/mcp/office-mcp/.venv`）运行，或通知总架构师代为执行；**不要把命令丢给用户**。
- 每次生成后，**可询问用户**是否需要把快捷方式复制到桌面（.lnk 仅是指针，不占内存、不占磁盘）；用户同意则复制，桌面放置不影响看板本体。

## 核心流程（推荐，最省事）
> **用户只需把更新的数据写进 Excel，其余全自动。禁止手工修改看板 HTML。**

1. 用 Excel MCP 将最新投递/笔面试进展写入 `05_选岗老师/数据/` 两个表（状态列取值：`过/挂/待参加/完成/是`，与状态机一致）。
2. 每周情报筛选后：把**所有适合用户的岗位**（用户自选 + AI 推荐）按分类（央国企/私企）**去重追加**到 `05_选岗老师/岗位情报/新增岗位情报.xlsx`（=计划投递岗位库：按★降序、持续累积、不重复、不删除；用户已投递的从情报挪到投递明细）。
3. 运行固定接口脚本：
   `python "05_选岗老师/可视化/update_dashboard.py"`
   （脚本自动：读两个 Excel + 新增岗位情报 → 规范化状态/批次 → 注入模板 → 生成看板）
4. 确认脚本输出的统计摘要与 Excel 一致（央国企已投/计划投/近期开闸行动清单、私企条数、情报条数）。

## 脚本约定（update_dashboard.py）
- 央国企表：`公司/网申日期/地点/岗位/是否投递/简历/笔试/一面/二面/三面/offer/链接/优先级/批次`
- 私企表：`公司/批次/测评截止时间/地点/优先级/岗位/是否投递/简历/测评/笔试/一面/二面/三面/offer/链接`（sheet=方向）
- 状态推导：按 offer→三面→二面→一面→笔试→测评→简历 取最深非空阶段；阶段值：`是→阶段名`、`通过→阶段+过`、`挂→阶段+挂`、`完成→阶段+已完成`。
- **任何阶段"挂"=终态**（红色标签、计入已挂/已淘汰）。
- **投递明细只展示"是否投递=是"的行**（投递总表只保留已投记录，未投岗位一律不进总表、只进新增岗位情报）。
- **行动清单**（仅央国企 Tab）：= 新增岗位情报中 `is_open()` 判定为**已开放网申**的岗位（判定：截止窗口含"网申中"→已开放；含"未开放"→未开放；空/无法判定→**视为已开放，宁可出错不可遗漏**），列：公司/截止日期/地点/岗位/入口。
- 新增岗位情报.xlsx = **计划投递岗位库**（所有适合岗位，按匹配度★降序、公司名次之；持续累积、去重、不删除；已投递的挪到投递明细）：分类=央国企 → 央国企 Tab「新增岗位情报 · 计划投递」模块；分类=私企 → 私企 Tab；模块标题日期自动取最新 `*情报清单.xlsx` 文件名（如 8-27）。截止窗口列规范写法：`网申中·截止YYYY-MM-DD` 或 `未开放·X月X日开闸(窗口)`；不确定的先搜索核实，仍无法确认的视为已开放。
- 看板模块（两 Tab 排版统一）：
  - 统计卡（累计投递/简历通过/已挂/进行中/笔试待参加/Offer，点击弹明细）
  - 投递概览（漏斗，两 Tab 同款）
  - 优先级分布 + 批次分布
  - 投递明细（可搜索/筛选/排序）
  - 新增岗位情报 · 计划投递（按分类展示，标题带数据日期）
  - **央国企额外**：近期开闸 · 行动清单（=情报中已开放网申的岗位，列：公司/截止日期/地点/岗位/入口）；**私企无行动清单**
- 分类归属：默认按所有制分央国企/私企；个别"招聘流程/难度接近私企"的特殊国企，由用户单独说明后归私企（写入私企投递记录表）。
- 支持深色模式；无 `实习(练手)` 等未规范化值。

## 自查
- 抽查 3 项数据与 Excel 一致；确认标题日期为最新；确认两个 Tab 模块结构一致（央国企多行动清单）；确认无手工改 HTML 的痕迹（数据必须由脚本注入）。

## 输出
- `05_选岗老师/可视化/投递看板.html`（覆盖更新）
- `00_交互区/系统输出/投递看板.lnk`（快捷方式，指向上述 HTML）
