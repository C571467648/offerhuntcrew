# 投递表更新流程

## 前置
- 读取主表：`05_选岗老师/数据/`（秋招央国企岗位投递表.xlsx / 秋招私企投递记录表.xlsx）
- 校验字段与状态取值：严格遵守 `02_系统配置/skill_共享/投递状态机/SKILL.md`
- **主表只记录已正式投递的岗位**：未投递的适合岗位一律放 `05_选岗老师/岗位情报/新增岗位情报.xlsx`（计划投递岗位库），不写入投递总表；用户确认投递后，从情报中移除该条并新增到总表（已投行）。
- **分类归属**：默认按所有制分央国企/私企；个别"招聘流程/难度接近私企"的特殊国企，由用户单独说明后归私企（写入私企表）。

## 步骤
1. 定位公司行：按「公司」匹配；无则新增行，补齐：公司/批次/地点/优先级/岗位/是否投递/链接。
2. 更新阶段状态：把用户反馈映射为规范取值（过/挂/待参加/已完成/无/-），写入对应阶段列。
3. 级联处理：
   - 某阶段「挂」→ 后续阶段清空。
   - 出现「offer」→ 标记。
   - 新增/改动投递日期、截止时间同步更新。
4. 自查：抽查 3 处，确认无口语取值、无错位（如把笔试结果填到一面）。
5. 完成后：
   - 生成/刷新看板（见 skill `选岗老师-仪表盘生成`）。
   - 写通知板 @班主任（进度）@学习指导老师（有笔面试结果时，供复盘素材）。

## 输出
- 主表更新（就地）
- 通知板文件：`01_共享区/00_通知板/[日期]_选岗老师_[接收者]_[主题].md`
