# 选岗老师 · 岗位采集工具使用手册

> 本手册由总架构师维护。选岗老师须按此规范使用岗位采集工具，所有采集结果最终归口 Excel 台账。
> 数据流：采集工具/用户情报源 → 岗位情报清单 → 用户确认 → 投递总表。

## 0. 工具总览

| 工具 | 定位 | 数据源 | 状态 |
|---|---|---|---|
| 浏览器直读（WebSearch/WebFetch/browser） | 主用 | 用户情报源（如有）、央国企官网 | 已启用 |
| mcp-jobs | 辅助（可选） | 多平台聚合（偏社招/私企） | 需总架构师指导安装后启用 |
| JobSniper (jobsniper) | 辅助（可选） | 智联招聘 | 需总架构师评估后启用 |

> 可选 MCP 是否需要安装、如何安装，一律由总架构师在配置阶段决定并指导（见 `03_总架构师/项目要求与MCP清单.md`）。

## 1. mcp-jobs 使用

- 入口：MCP 工具（名称 mcp-jobs），提供两个工具：
  - `mcp_search_job`：按 关键词+城市（+薪资/经验/页码）搜索职位
  - `mcp_job_detail`：按 URL 获取职位详情
- 用法（自然语言即可，模型会自动调用）：
  - "用 mcp-jobs 搜索 {意向城市} 的 C++ 开发职位"
  - "用 mcp_search_job 搜 keyword=C++ city={意向城市}"
- 输出为标准化职位信息，**收集后先入情报清单，勿直接入台账**。

## 2. JobSniper 使用（可选）

- **定位**：岗位知识库检索（`find_job_detail`、`jobsniper://persona`）。
- **注意**：智联自动采集（`launch_zhilian_*`）依赖 WSL 环境，仅高级用户可选启用，默认不启用。是否启用由总架构师评估。
- 入口：MCP 工具（名称 jobsniper）。

## 3. 数据归口（强制）

- 任何工具采集的岗位，一律先写入 `05_选岗老师/岗位情报/` 的《岗位情报清单.xlsx》。
- 情报清单 → 通知板@用户确认 → 确认后按投递状态机录入 `05_选岗老师/数据/` 投递总表。
- 禁止把采集结果直接当台账使用；禁止绕过用户确认直接入总表。

## 4. 例行作业（每周）

1. 浏览器扫描用户情报源（如有，见 README 5.1），过滤意向地点+技术岗。
2. （可选）mcp-jobs 搜"{意向城市} + 岗位关键词"，补充私企情报。
3. 合并去重 → 更新《岗位情报清单.xlsx》→ 通知板@用户。
