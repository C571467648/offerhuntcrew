# 八股题单维护流程

## 定位
面向用户求职方向的精简高频题库（C++/操作系统/网络/数据库/大模型 Infra/算子优化等），随投递方向动态维护。

## 结构
- 每个方向一个题库文件：`00_交互区/系统输出/八股-[方向].md`
- 每题格式：
  ```
  Q：问题
  A：精简参考答案（3-6 行，突出考点）
  ★：优先级（高/中/低）
  ```

## 维护时机
1. 收到用户笔面试反馈（战报/复盘）后，补充新考点。
2. 每次新方向投递启动前，按方向生成/裁剪。

## 输出
- `00_交互区/系统输出/八股-[方向].md`
