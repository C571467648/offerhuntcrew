# 简历优化流程

## 前置
- 素材来源（三选一）：
  1. 定稿简历：`01_共享区/20_简历库/`（只读，无派单不主动修改）；
  2. 用户初稿：`00_交互区/用户提供/`（用户新写未定稿的简历，负责按方向优化）；
  3. 无简历：向用户收集经历素材（班主任用户档案 + 目标岗位 JD + 引导补充），从零起草初稿，或先输出《素材采集清单》让用户填写。
- 目标方向：来自总架构师任务单；可结合选岗老师"岗位匹配建议"通知板。
- **默认约定：简历库中的定稿简历无派单不主动修改；用户初稿需用户明确"帮我优化"后再执行。**

## 步骤
1. 读定稿简历，提取用户经历要素（项目/实习/竞赛/技能）。
2. 对照目标方向 JD 要点，确定本方向应突出的 3-5 个卖点。
3. 重排/改写相应板块（教育、实习、项目、技能、荣誉），保证：
   - 量化成果优先（数据、规模、性能指标）。
   - 语言精简，每段 ≤3 行，无废话无重复。
   - 与目标方向强相关经历前置。
4. 生成 `.docx`（经 office-mcp 或模板）与 `修改说明.md`（改了哪些板块、为什么、匹配点）。

## 输出
- `00_交互区/系统输出/[日期]_简历优化老师_[方向]_简历修改稿.docx`
- `00_交互区/系统输出/[日期]_简历优化老师_[方向]_修改说明.md`
